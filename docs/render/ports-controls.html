侧键与接口：认准外壳 / PCB 丝印

功能示意图 · 非比例机械图，不表示各批次接口的精确左右顺序

A日常数据接口

USB

原生 USB → Codex HID / Desktop 配置
带数据的 USB 线；支持无电池供电使用

B开发与恢复接口

USB TO UART

USB 转串口 → 刷写 / 启动日志 / 故障定位
不能代替日常 Codex 数据通道

C电源侧键

PWR

短按：按设置进入 Connected / Ultra 待机
长按：板载电源关机路径
恢复方式取决于进入的电源状态

D设置与救砖侧键

BOOT

运行中短按：设置中心
长按：当前槽位重新配对流程
按住再上电：ROM 下载恢复

E板侧绿色指示灯

CHG LED

微雪原生充电指示逻辑
不等同于 BLE 连接灯或实时电量表

F内部电池连接器

PH2.0 · 2P

单节 3.7V 电池；安装前核对正负极
首次使用可以不接电池
