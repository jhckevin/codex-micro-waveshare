# 扩展底座与装配资料

此目录用于存放底座的 STL、STEP、3MF、工程源文件、打印方向、支撑建议和装配图。

目前尚未提供可打印模型。作者后续补充模型及实测尺寸后，需同时记录：

- 两个 USB-C、PWR、BOOT、扬声器和电池线的避让；
- 螺丝直径、牙型、长度、垫片和热熔铜螺母规格；
- 电池仓净尺寸、固定方式及软包电芯膨胀余量；
- 打印材料、层高、壁厚、填充、支撑方向和装配顺序；
- 实物试装照片和模型版本。

当前电子配置针对 606080、3.7 V、4000 mAh / 14.8 Wh、ATL A 类带保护板电池。`606080` 不能代替实际来料的长宽厚、公差、引线方向和保护板外形；最终电池仓尺寸必须以实物测量为准。

在模型、螺丝和实物试装完成前，不应把此目录描述为“可直接打印的完整底座”。
