# 扩展倾斜底座、打印与装配

此目录保存 Waveshare ESP32-S3-Touch-LCD-4B 扩展底座的可打印网格、Fusion 360 工程与装配说明。底座用于隐藏电池、保护接线并提供约 21° 的桌面倾角。

## 电池仓

当前电子方案使用 606080、3.7 V、4000 mAh / 14.8 Wh、ATL A 类带保护板软包电池。底座允许改用更大容量的长方形电池，但必须满足：

- 电池宽度不超过 **60 mm**；
- 实测厚度和长度小于仓内净空间；
- 为软包膨胀、保护板、焊点与线材弯曲留出余量；
- 不挤压、折弯或刺穿软包；
- PH2.0 极性必须与板卡一致；
- 不让电池遮挡 USB-C、PWR、BOOT、扬声器或散热区域。

“606080”只是规格名称，不能代替实物卡尺测量。

## 紧固件

现有建模资料配套：

- M2×10 沉头螺丝 2 颗；
- M2×35 沉头螺丝 2 颗；
- M2×0.4 六角螺母 4 颗，对边 4 mm、厚 1.6 mm。

不同打印材料和层高会改变孔径。先打印小件验证 M2 配合，不要强行把金属螺丝拧入明显过紧的塑料孔。沉头应与孔位贴合但不得拉裂外壳；逐角分次拧紧，避免屏幕受扭。

## 打印建议

- 首选 PLA/PETG 进行试装；高温环境优先 PETG 或更耐热材料；
- 建议层高 0.20 mm，至少 3 道墙，底部 4～5 层；
- 螺柱和薄壁处降低速度；
- 让大平面贴合平台，按切片预览添加局部支撑；
- 首次只打印底座并空载试装，再放电池；
- 检查两个 USB-C、PWR、BOOT 和线材弯曲半径；
- 装配后确认底座不压屏幕、不顶电池、不遮挡 CHG LED。

## 装配顺序

1. 断开 USB 和电池。
2. 清除底座毛刺，试装四颗螺丝和螺母。
3. 空载放入设备，检查侧键和两个 USB-C。
4. 测量电池并加绝缘软垫，固定时不要使用尖锐金属件压住电芯。
5. 整理电池线，避免被螺柱或外壳夹住。
6. 合拢后对角、分次拧紧。
7. 先接低风险供电检查，再观察电池状态和充电指示。
